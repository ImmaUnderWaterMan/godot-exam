# Самостоятельное задание по Godot Engine
---
## Описание
Необходимо реализовать игровую механику в соответствии с выбранным вариантом. Проект должен быть выполнен чисто, с использованием лучших практик программирования на GDScript.
---
## Вариант 1: Базовое перемещение и карта

### Цель
Создать сцену, где персонаж может свободно перемещаться по карте, построенной с помощью TileMap, учитывая коллизии.

### Требования к реализации

1. **Карта (TileMap / TileMapLayer)**
   - Создать и настроить `TileSet` с минимум 3-мя различными тайлами (например: пол, стена, декор).
   - Разместить тайлы на сцене, создав замкнутое пространство или уровень с препятствиями.
   - Настроить физические слои для стен/препятствий.

2. **Персонаж (Player)**
   - Создать сцену персонажа (на основе `CharacterBody2D`).
   - Реализовать скрипт управления:
     - Перемещение с помощью клавиш WASD или Стрелок.
   - Настроить `CollisionShape2D` для персонажа.

### Критерии оценки
| Критерий | Вес |
| :--- | :--- |
| Корректная настройка TileMap и коллизий | 40% |
| Рабочее управление персонажем | 60% |
---

## Вариант 2

### Цель
Расширить базовую механику перемещения, добавив врага, систему здоровья и обмен уроном.

### Требования к реализации

1. **Карта и Персонаж (Базовые требования из Варианта 1)**
   - Наличие настроенного `TileMap` с коллизиями.

2. **Противник (Enemy)**
   - Создать сцену врага.
   - Враг должен иметь параметр `Health` (здоровье).
   - Враг должен наносить урон игроку при столкновении или атаке.

3. **Боевая механика Игрока**
   - Игрок должен иметь параметр `Health`.
   - Реализовать возможность атаки
   - При получении урона здоровье должно уменьшаться.
   - При достижении 0 HP должна происходить реакция (перезапуск сцены).

### Критерии оценки
| Критерий | Вес |
| :--- | :--- |
| Карта и перемещение игрока | 30% |
| Логика противника | 30% |
| Система нанесения/получения урона | 40% |
